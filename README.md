# Успіх — електронний журнал

Інформаційна система обліку успішності студентів. Лабораторна робота №6–7 з професійної практики програмної інженерії, ІПЗ-41, Карпатський національний університет імені Василя Стефаника.

React + Vite на фронтенді, локальний REST API на Node.js (дані в JSON). Цільова архітектура: React → Django REST Framework → PostgreSQL.

## Запуск

Потрібен Node.js 22.12+.

```sh
npm install
npm run dev      
npm run build    
npm start       
npm test        
npm run demo    
```

Зміни зберігаються в `server/data.json`. Щоб повернути початкові дані, зупиніть сервер і видаліть цей файл.

## Структура

- `src/` — інтерфейс (`App.jsx`, `components/`, `domain.js`, `api.js`, `styles.css`)
- `server/` — API (`api.mjs`), автентифікація, початкові дані
- `shared/` — типи занять, шкали, факультети
- `tests/` — автоматичні перевірки
- `db/` — SQL-скрипти бази даних (лабораторна №5)

## Обмеження

Це навчальний прототип: JSON замість СУБД, спрощена автентифікація, шкала переведення балів демонстраційна.
